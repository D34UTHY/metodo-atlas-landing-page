# metodo-atlas-landing-page

Landing page profissional para o curso de investimentos **Método Atlas**.
Dark & Premium. Desenvolvida com HTML, CSS e JavaScript vanilla.

O projeto foi feito para um cliente (freelance) que, buscava uma página de vendas de visualização rápida, para que pudesse captar o máximo de vendas possível, tanto com redirecionamento de seu curso gratuito quanto do tráfego pago que havia realizado, com um vídeo de apresentação que enviava para essa página.

Acesse a Landing Page e veja você mesmo no Github Pages: https://d34uthy.github.io/metodo-atlas-landing-page
